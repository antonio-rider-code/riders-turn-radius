# Радиус поворота — учебная модель Riders School

Интерактивная модель: как радиус поворота лыж и сноуборда зависит от угла закантовки,
радиуса бокового выреза и наклона тела.

**Открыть:** https://antonio-rider-code.github.io/riders-turn-radius/

- R = R выреза × cos θ — классическая геометрическая модель резаного поворота.
- Вид сверху: S-образный след в масштабе, лыжи едут с расчётной скоростью равновесия.
- Вид спереди: закантовка θ, наклон тела λ, центр масс и ангуляция.

Модель идеальная: твёрдый склон, ведение на канте без проскальзывания, уклон не учитывается.
Вся страница — один файл `index.html`, без сборки.
